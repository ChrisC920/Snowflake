# Code of Conduct

Snowflake follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, assume good intent, and keep discussion about the work. Harassment, insults and personal attacks aren't tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer through GitHub (use the "Report content" option on the comment or contact the repository owner). Reports are kept confidential. The maintainer may remove content, or block people who break this code, at their discretion.
