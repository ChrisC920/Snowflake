# Snowflake brand and design guide

## Style

Modern macOS with Liquid Glass (macOS 26+), restrained and close to Apple's own apps.

- **Glass belongs to controls and navigation only**: the menu bar panel and its tiles, toolbars, buttons and the Settings sidebar. Content uses standard materials. Use `snowGlass(in:)` and `SnowGlassContainer` from `SnowflakeKit`; they fall back to materials on macOS 15.
- **Prefer stock components.** `NavigationSplitView`, grouped `Form`, system toggles and pickers adopt Liquid Glass automatically.
- **One signature motion.** Panel tiles morph between collapsed and expanded with `glassEffectID`. Everything else uses the single `Animation.snow` spring, and honours Reduce Motion.
- **Follow system settings.** Accent color (by default), Reduce Transparency, Increase Contrast and the Liquid Glass transparency slider.

## Palette: Frost

A subtle, cool take on Apple's dark appearance. Defined in `Sources/SnowflakeKit/Theme/FrostPalette.swift`.

| Token | Dark | Light ("Snowfield") | Use |
|---|---|---|---|
| Night / background | `#0D1015` | `#F2F5F9` | Window background |
| Slate / surface | `#1B1F26` | `#FFFFFF` | Raised surfaces |
| Frost glass / groupedFill | `#262B34` | `#E6EDF5` | Grouped sections |
| Hairline | `#2C333F` | `#D5DEE9` | Separators |
| Snow / label | `#F1F4F8` | `#1B2028` | Primary text |
| Mist / secondaryLabel | `#A3ACB9` | `#5D6878` | Secondary text |
| **Ice** (default Frost accent) | `#5AB0F0` | `#3D8FD6` | On-states, selection, primary action |
| Glacier | `#3D8FD6` | `#2F78BF` | Optional accent |
| Aurora | `#6FD3C1` | `#2FA894` | Optional accent |
| Slate accent | `#8C9BB0` | `#5D6878` | Optional accent |
| Ember | `#E8A25A` | `#C97A2E` | Warnings |

Color is for on-states, the selected choice and the primary action. Never decoration.

## Icon

"Glass split, soft sheen": a six-arm rounded snowflake on an ice gradient (`#8ED2FF` top-right → `#2C74DA` bottom-left), split at 45°. The top-left half is solid white and the bottom-right half is white at 76%, with soft sheen bands parallel to the split.

Source of truth: `scripts/make-icon-art.py`. Run `make icons` after changing it.

### Three forms

| Form | Asset | Where |
|---|---|---|
| **App icon** (with tile) | `AppIcon.icon` (Icon Composer, layered) | Dock, ⌘-Tab, Finder, Spotlight, notifications, About, README, website |
| **Mark** (no tile) | `SnowflakeMark` (template PDF) | Inside Snowflake's own UI: panel header, Settings sidebar, empty states. Takes the text color; glass half at 68%. |
| **Menu bar glyph** | `MenuBarIcon` (18pt template PDF) | The menu bar item only |

Rule: the tile appears only where Snowflake is shown as an app among other apps. Never put the tile inside glass panels, menus or sidebars, and never recolor it.

The `.icon` file has two groups: the snowflake (both halves, Liquid Glass on) above the sheen (glass off). Its dark appearance swaps the gradient for `#283245` → `#0D1117`. Clear and tinted appearances are generated by the system. Open `Snowflake/Resources/AppIcon.icon` in Icon Composer (Xcode → Open Developer Tool) to preview or fine-tune.
